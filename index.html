Footstep Power Generation

An electronics experiment exploring how pressure on piezoelectric discs can produce electrical signals for a small demonstration system. The project involves testing sensor output and exploring ways to display or use the generated signal.

Arduino pH Sensor

A sensor-and-display experiment using an Arduino and an LCD to explore pH readings and how sensor values can be presented. The project focuses on reading sensor output, displaying measurements, and comparing readings from different sample solutions.
